## Where the SDK stands

`auth-ai` `0.1.0` is the first release of the Python port of the TypeScript SDK [`@circle-rd/auth-ai`](https://docs.circle-cyber.com/auth-ai/typescript/). The port reproduces its behaviours, wire contract and error codes. The public API is not stable: while the major version is `0`, a breaking change bumps the minor version, and the [changelog](https://github.com/circle-rd/auth-ai-py/blob/main/CHANGELOG.md) lists it with a migration note.

The surface that exists today is described in the [Reference](/docs/reference/configuration): the async OIDC relying party, the backend-for-frontend handlers, the Starlette and FastAPI adapter, bearer token verification, back-channel logout, the wallet and gateway clients, and the machine API for billing and consumption.

## Not available yet

| Gap | What to do today |
| --- | --- |
| **No Django or Flask adapter** | The framework-agnostic `WebRequest` and `WebResponse` handlers mount in any framework through a small bridge. The [other frameworks](/docs/guides/backend/other-frameworks) guide shows an ASGI bridge, with Litestar and Django under ASGI. |
| **No synchronous facade** | The SDK is async only, built on `httpx2.AsyncClient`. A synchronous WSGI application cannot host it directly. |
| **No frontend code** | The browser client and the React and Vue bindings are in the TypeScript package. See [Use the TypeScript client](/docs/guides/frontend/use-the-typescript-client). |
| **No database-backed stores** | `SessionStore`, `GrantStore`, `GrantLock` and `ReplayStore` are protocols with in-memory implementations. [Implement the stores](/docs/guides/backend/custom-stores) shows SQLAlchemy and Redis sketches. |

## Staying aligned with the TypeScript SDK

The wire contract (the BFF routes, the cookie formats and the error codes) is shared with the TypeScript SDK: a change to it is made in both SDKs or in neither. A feature of the TypeScript SDK may therefore reach the Python port after it ships there.

## Not planned here

The SDK has no debit API, by design: the LiteLLM gateway debits the wallet after each call. See [Credit wallet and LiteLLM gateway](/docs/concepts/wallet-and-gateway).

To suggest or discuss a feature, open an issue on [GitHub](https://github.com/circle-rd/auth-ai-py/issues).
